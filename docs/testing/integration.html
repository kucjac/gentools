Integration testing

Validate real consumer workflows.

The scenario suite exercises Gentools as a consumer would, from a temporary snapshot of tracked source.

Run the suite

make test-integration

This runs inspect, generated, crosspackage, and invalid. Its output is candidate-source evidence: it validates the checked-out contract, not a published release.

For published-module evidence, use the tag-triggered release smoke workflow. It intentionally has no local replace directive.

Generated protobuf preflight

Generated fixtures are regenerated rather than edited manually. Ensure protoc and protoc-gen-go are installed and available on PATH, then run:

protoc -I internal/integration/protobuf -I /usr/include \
  --go_out=paths=source_relative:internal/integration/protobuf \
  internal/integration/protobuf/models.proto
git diff --check -- internal/integration/protobuf/models.pb.go

Record generator versions with any generated-output change, then rerun the generated consumer scenario.
