Guides / Test gaps

Test quality

Prioritize tests by contract risk.

The behavior inventory keeps coverage evidence connected to the public behavior it is meant to protect.

Run the assessment

make test-gaps

Use the Go version declared in .go-version. The assessment verifies that every exported parser and types declaration is classified, its evidence path exists, and high-risk gaps are rejected.

Use the results well

Coverage counts basic blocks; it does not prove public contracts or useful assertions. Add new symbols to the behavior inventory in the same change, document why generated or integration-only behavior is excluded, and add focused regression tests for high-risk behavior.

The behavior inventory is available as a reviewable report.
