Runnable example

Generate typed Go accessors.

A consumer-owned CLI that scans one struct through Gentools and writes getters only for the fields you select. It does not add a Gentools generator API.

Prerequisites

Use the Go version declared in .go-version.

Run it

go run ./examples/codegen/struct-accessors \
  -input ./examples/codegen/struct-accessors/testdata \
  -type Account \
  -fields ID,Email \
  -output /tmp/account_accessors.go

What it generates

// Code generated by gentools struct-accessors; DO NOT EDIT.

package models

func (v Account) GetID() string {
	return v.ID
}

func (v Account) GetEmail() string {
	return v.Email
}

The generator validates the selected struct and fields, rejects missing, private, or repeated field names, and preserves the requested field order. Compare the full formatted result with the checked-in golden file.

If loading fails, confirm that the input is a loadable Go package, then run make test-quality for the complete validation workflow.

Struct summary

Use this smaller discovery example when you need an inventory of the structs Gentools finds before deciding what to generate.

Input and command

The input package is examples/codegen/struct-summary/testdata. With the same prerequisite Go version, run:

go run ./examples/codegen/struct-summary \
  -input ./examples/codegen/struct-summary/testdata \
  -output /tmp/summary.go

Expected result

The generated source records the two structs discovered in the input package. Inspect /tmp/summary.go and compare it with the checked-in golden file:

// Code generated by gentools struct-summary; DO NOT EDIT.

package generated

var StructNames = []string{"Account", "Session"}

If the summary is empty, check that the input directory is a loadable Go package and declares named structs. If it still differs from the golden file, run make verify-docs to reproduce the validated example check.

OpenAPI contract

Use the contract example to turn source-adjacent operation comments and public model metadata into one OpenAPI 3 document. It is a consumer-owned example and does not add a generator API to Gentools.

Input and command

Run it against examples/codegen/openapi-contract/testdata:

go run ./examples/codegen/openapi-contract \
  -input ./examples/codegen/openapi-contract/testdata \
  -output /tmp/gentools-openapi.json

An operation comment uses @openapi method=GET route=/pets/{id} summary="Get a pet" response=200:Pet. The first version supports documented GET operations, path parameters, primitive/pointer/slice/struct model fields, JSON tags, and shared model references.

Expected result and diagnostics

Inspect /tmp/gentools-openapi.json and compare it with the checked-in golden contract. Malformed annotations, duplicate method/route pairs, unresolved models, and unsupported field shapes fail before output is replaced. Run make verify-docs to validate the published example from an isolated tracked-source snapshot.
