Runnable example

Generate typed Go accessors.

A consumer-owned CLI that scans one struct through Gentools and writes getters only for the fields you select. It does not add a Gentools generator API.

Prerequisites

Use the Go version declared in .go-version.

Run it

go run ./examples/codegen/struct-accessors \
  -input ./examples/codegen/struct-accessors/testdata \
  -type Account \
  -fields ID,Email \
  -output /tmp/account_accessors.go

What it generates

// Code generated by gentools struct-accessors; DO NOT EDIT.

package models

func (v Account) GetID() string { return v.ID }

func (v Account) GetEmail() string { return v.Email }

The generator validates the selected struct and fields, rejects missing, private, or repeated field names, and preserves the requested field order. Compare the full formatted result with the checked-in golden file.

If loading fails, confirm that the input is a loadable Go package, then run make test-quality for the complete validation workflow.

A smaller discovery example

struct-summary lists the struct names that Gentools discovers in a package. Use it when you need a quick inventory rather than generated methods.
