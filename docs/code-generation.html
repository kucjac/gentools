Generate a struct summary

This consumer-owned example inspects Go structs and emits deterministic Go source; it does not add a Gentools generator API.

Prerequisites

Use the Go version in .go-version.

Run

go run ./examples/codegen/struct-summary -input ./examples/codegen/struct-summary/testdata -output /tmp/summary.go

Expected output

The output contains Account and Session; compare it with the checked-in golden file.

Troubleshooting

Confirm the input is a loadable Go package and run make test-quality for validation.
