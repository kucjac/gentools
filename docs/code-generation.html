Runnable example

Generate a struct summary.

A consumer-owned example that inspects Go structs and emits deterministic Go source. It does not add a Gentools generator API.

Prerequisites

Use the Go version declared in .go-version.

Run it

go run ./examples/codegen/struct-summary \
  -input ./examples/codegen/struct-summary/testdata \
  -output /tmp/summary.go

What to expect

The output contains Account and Session. Compare it with the checked-in golden file.

If loading fails, confirm that the input is a loadable Go package, then run make test-quality for the complete validation workflow.
